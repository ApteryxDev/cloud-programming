Available, fast, scalable.

This page is served from AWS by S3 and CloudFront. It is designed around three properties the assignment asks for.

Highly available

The files live in S3, which stores copies across several data centres. CloudFront sits in front of that, spread across many edge locations, so there is no single machine whose failure can take the site down.

Low latency, anywhere

CloudFront caches this page at edge locations around the world. Your request was answered by whichever one is closest to you, not by a single server in one country.

Autoscaling

There are no servers to scale. S3 and CloudFront absorb extra traffic on their own at the platform level, so the same setup serves one visitor or one million without any manual change.
